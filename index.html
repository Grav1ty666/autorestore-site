01 / Designed for recovery

把复杂的准备，
留在部署时。

备份和恢复不应从复杂配置开始。选择磁盘、查看操作计划，然后部署独立恢复环境。

⌘

终端部署

自动扫描磁盘与空间，选择启动和备份分区所在磁盘后部署。

◷

开机即可选择

从启动菜单进入备份或恢复流程，也可以启动已识别的系统。

▤

独立恢复环境

即使 Windows 无法进入，也可尝试启动恢复环境，还原基准镜像。

02 / Organized by design

备份有序，
恢复有据。

镜像保存在独立的 BACKUP_OS 分区。首次成功备份作为基准，后续备份以时间戳命名；恢复时使用固定的基准镜像。

03 / Get started

从安装到恢复，
每一步都清楚。

先创建备份，需要恢复时再进入启动菜单。运行前请阅读项目文档并备份重要数据。

01 / INSTALL

部署恢复环境

运行安装程序，在部署工具中选择磁盘并确认操作计划。

02 / BACKUP

创建系统备份

进入启动菜单，选择 Backup OS，等待备份完成。

03 / RECOVER

需要时恢复

选择 Recovery OS，从基准镜像恢复 Windows 分区。
