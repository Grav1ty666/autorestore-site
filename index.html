立即下载查看文档
01 / DEPLOY

部署，从容开始。

在 Windows 中运行终端部署工具，扫描磁盘和空间，选择启动与备份分区所在磁盘，确认操作后部署 Clonezilla 恢复环境。

02 / BACKUP

镜像管理，清晰有序。

备份保存在独立的 BACKUP_OS 分区。首次成功备份作为基准镜像，后续备份使用时间戳命名；恢复时使用固定的基准镜像。

03 / RECOVERY

独立环境，随时恢复。

通过 UEFI 启动菜单进入独立的 Clonezilla 环境，即使无法进入 Windows，也可尝试恢复已备份的系统分区。

04 / SAFETY

操作之前，先看清楚。

部署前展示磁盘操作计划；程序记录部署日志并提供错误码。恢复会覆盖 Windows 分区，请在操作前确认目标并另行备份重要数据。

05 / GET STARTED

三步，准备就绪。

下载安装并部署→启动菜单选择 Backup OS 或 Recovery OS→等待操作完成
使用须知
面向 x86-64 UEFI/GPT Windows 设备；不支持 Secure Boot 和 BitLocker。工具只备份和恢复 Windows 所在分区，不是完整磁盘备份。部分功能与多系统兼容性尚未完成端到端验证，使用风险由使用者自行承担。
