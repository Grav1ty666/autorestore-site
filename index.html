01 / Designed for recovery
一次性部署，
后续零配置
部署阶段选定磁盘、确认分区方案，完成后恢复流程无需额外设置。
⌘
终端部署
自动枚举磁盘、检测可用空间，选定目标盘即可完成部署。
◷
开机即可选择
开机进入启动菜单，选择备份、还原，或是正常启动 Windows。
▤
独立恢复环境
Windows 无法启动时，仍可进入恢复环境，还原基准镜像。


02 / Organized by design
镜像目录规则化，
避免误选
镜像存放于隐藏 BACKUP_OS 分区。首次成功备份生成基准镜像，后续备份按时间戳命名；默认从基准镜像执行还原。

03 / Get started
三步使用流程
部署环境 → 创建备份 → 故障时还原。使用前务必阅读文档，另行备份关键资料。
01 / INSTALL
部署恢复环境
运行安装程序，选择磁盘，确认分区方案。
02 / BACKUP
创建系统备份
重启，启动菜单选择 Backup OS，自动执行备份。
03 / RECOVER
故障还原
启动菜单选择 Recovery OS，自动还原 Windows 分区。


Ready when you need it
系统故障，随时回滚
开源独立的 Windows UEFI 系统备份还原工具
下载 Windows 安装程序 ↓查看 GitHub ↗
仅支持 x86-64 UEFI+GPT 的 Windows；不兼容 Secure Boot、BitLocker。
还原操作会直接覆盖 Windows 分区，不提供 EFI 分区或全盘备份。多系统场景兼容性未完全验证。
请提前单独备份重要数据，使用风险由使用者自行承担。
